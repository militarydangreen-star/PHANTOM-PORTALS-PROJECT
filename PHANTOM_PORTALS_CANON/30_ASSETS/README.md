## Sidecars
Every asset has a `<file>.meta.json` beside it:

```json
{
  "id": "PP-BRAND-003", "file": "phantom-monogram.svg", "title": "Phantom monogram",
  "status": "CURRENT", "canon_version": "1.0.0", "kind": "vector", "format": "svg",
  "dimensions": "128x128", "bytes": 194238, "sha256": "5de9…7501",
  "usage": "…", "rules": ["…"], "tags": ["…"],
  "license": "…", "source": { "artifact": "…", "version": "…", "path": "…", "fetched": "2026-10-29" }
}
```

`sha256` and `bytes` must match the file. `validate-canon.py` fails if a file changes without its sidecar being updated, so nothing changes silently between releases.

## Adding an asset
1. Put the file in the right folder (lowercase-kebab-case name, no spaces).
2. `python3 80_TOOLS/index-assets.py --new path/to/file --id PP-<SERIES>-<NNN> --title "…" --kind vector|raster|font|template` — writes a starter sidecar (status DRAFT unless `--status` says otherwise) and rebuilds the index.
3. Fill `usage`, `rules`, `tags`, `license` and `source` (for generated images: `source.prompt_id` and `source.tool`).
4. Generated images must pass [PP-AUD-IMAGE-001](../20_PROMPT_LIBRARY/design-audit/PP-AUD-IMAGE-001-generated-image-review.md) first.
5. Promote DRAFT → CURRENT only with the owner's approval, and log it in the [CHANGELOG](../00_START_HERE/CHANGELOG.md).

**Changing a file:** edit it, then run `index-assets.py` with `--new` for the same path (it refreshes `sha256`/`bytes` and keeps the other fields) — or update the two fields by hand — and rebuild the index.

**Icons:** the design-system copy in `10_DESIGN_SYSTEM/iconography/` is the source. Copy changes here and run `python3 80_TOOLS/build-icon-data.py`; the `mirrors` check fails if the two folders differ.
