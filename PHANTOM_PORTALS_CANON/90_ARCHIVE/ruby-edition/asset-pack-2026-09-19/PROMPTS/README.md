# Phantom Portals — Ruby Edition assets

44 relic icons + 44 outline icons. Matching crest, ring-and-spire and hood marks,
standard, divider, frame, generated hero, 3 local fonts with licenses, and CSS.

Use relics at 64 px or larger, outlines at 24–32 px. The hero PNG is unchanged
from its generated original. See GENERATION-PROMPT.md for provenance.
Deep ruby is #A0112B; readable ruby ink on dark surfaces is #EE5367.
Preserve font licenses when redistributing. The full-site ZIP supplies the
interactive gallery, landing page, and design guide.
