# PHANTOM PORTALS — CODEX MASTER HANDOFF v3.1

**Purpose:** One complete, versioned package to take the **existing** Phantom Portals USB command center from frozen visual prototype to a real Chromium-based Windows portable application, without replacing established user files or changing the design.

**User's part:** Select/open the **actual current Phantom Portals project folder** in Codex, attach or place this extracted handoff folder where Codex can read it, and paste `COPY_PASTE_INTO_CODEX.txt`. There is no need to manually program, install dependencies, or edit files unless access/approval is required.

**Codex's part:** Audit, branch, implement, test, resolve non-destructive technical issues, provide clear actual evidence and build artifacts, and ask only for approvals that genuinely require the user.

1. `COPY_PASTE_INTO_CODEX.txt` — master command.

7. `docs/04_EXECUTION_GATES_AND_ISSUES.md`, `docs/05_ACCEPTANCE_TESTS.md`, `docs/06_REPORT_TEMPLATE.md` — implementation controls.

## Primary folders
- `01_APPROVED_DESIGN_v3.1/`: complete original 38-file frozen prototype, all eight screen references, tests, tokens, UI source, screenshot set.
- `02_MASTER_VISUAL_ASSETS_v2.0/`: 15 source/image/vector files including `.ora`, transparent raster layers and emblem. Some layers are extracted/reconstructed from originally flat generated art, not independently generated painting originals.
- `03_OPTIONAL_CHROMIUM_SEED_v0.1/`: the earlier Electron source starter; audit before use; **not** a known working or secure released browser.
- `04_HISTORICAL_REFERENCE_DO_NOT_EXECUTE/`: previous `PLAN.md` and unrelated launcher snapshot. Old alpine visual requirements are superseded. Do **not** execute launcher or treat it as current state.
- `docs/`: bridge architecture, live-repo audit, navigation map, implementation gates, QA requirements, risk boundaries and report template.

## Important limitations
This package contains prior design files and starter source, **not the user's current working USB repository**, private catalogs, credentials, binaries, or a verified Windows portable executable. The frozen v3.1 preview previously reported 21 tests (12 browser simulation checks and 9 source/runtime tests) against a **visual prototype only**. Its demo values are not real device measurements. Codex must inspect the actual workspace before editing.

**Do not replace** the existing USB content with this folder. Keep this handoff alongside the repository (or attached separately in Codex) and use it as a **reference and work order**.
