# Component reference

One folder per component, copied from the design system: `README.md` (long-form usage), `card.md` (generated props card) and `preview.html` (the design system's live preview snippet — it expects the design-system page around it; the [gallery](../../gallery/index.html) renders the same examples standalone).

These files are reference snapshots. Edit the family docs in `../` instead; refresh these only from a new design-system export.

Note: preview snippets use sample data (e.g. "DIMM A1 failed 3 of 12 passes") to demonstrate layouts. Production screens show real readings only.
