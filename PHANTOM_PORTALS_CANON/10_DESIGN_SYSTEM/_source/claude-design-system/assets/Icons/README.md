# Icons

20 UI icons on a 24px keyline grid with 2px padding: 1.5px square-capped, mitred `#151519` strokes and exactly one `#A0112B` accent. The accent marks what the icon *does*: the lens handle, the cursor, the active node.

- In the interface they render as masks via `<Icon>` / `.pp-icon`, so they take one ink (`currentColor`).
- Sizes: 16, 20 (default), 24. Below 16px use a text label.
- For large, illustrative uses (tiles, launchers, empty states) use the matching **Feature Icons**.

Set: search, home-portal, back, forward, reload, bookmark, terminal, diagnostics, ai-core, tools, folder, network, shield, cpu, cloud, settings, power, alert, check, close.
