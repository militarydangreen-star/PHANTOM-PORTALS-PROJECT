# Vectors

Original Ink Protocol artwork for heroes, headers, edges and transitions. Every Trash Polka mark is simulated rather than drawn: dry-brush strokes are built from 60–170 individual bristles that run out of ink, with paper streaks opening as the brush dries; splatter falls off in a power law from the point of impact, with tadpole droplets and mist; halftone uses a rotated 45° screen.

**Trash Polka:** `brush-slash` (crimson cut), `brush-stroke` (ink swash), `brush-x` (crimson cross), `splatter-ink`, `splatter-crimson`, `ink-drips`, `halftone-fade`, `halftone-disc`, `torn-edge` (ink over crimson), `enso-ring` (dry brush), `engraved-hatch` (cross-hatched disc).

**Isometric / HUD:** `iso-cube` (hatched and solid faces), `iso-grid`, `hex-cluster`, `hud-ring` (graduated), `target-reticle`, `circuit-trace`, `coordinate-ruler`, `laser-lines` (`accent-electric`, decorative only).

Rules: at most three vectors per composition, one crimson; pair each chaos mark with a precision mark; keep them away from controls, tables and reading text. The dry-brush files are 0.3–0.8 MB, so export a PNG for heavy pages.
