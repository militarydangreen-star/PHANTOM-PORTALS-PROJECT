# Feature Icons

The same 20 glyphs as Trash Polka badges on a 160px artboard. Each has a dry-brush ink ensō, a crimson dry-brush dab, a halftone quarter-disc and a graduated tick arc, with the glyph drawn at 3x in ink + crimson. Each badge's composition is seeded individually, so no two are identical.

Use at 56–160px for tool tiles (`<ToolTile feature>`), launchers, onboarding, empty states and documentation. Never use them in dense UI, toolbars or tables; use **Icons** there. Render through `<FeatureIcon name="…" size={72} />`.
