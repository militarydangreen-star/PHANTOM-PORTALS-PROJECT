# Logos

**The Phantom.** The hooded reaper of the project's canon, redrawn in the Ink Protocol language. It has a pointed hood, a faceted beaked mask with crimson eye slits, layered pauldrons, and segmented gauntlets cupping a crimson singularity. The cloak is engraved with hatching and rim-lit from the upper left; its hem tatters into ink drips. It stands inside a precision instrument: a graduated ring, a dry-brush ensō, an isometric cube frame and a target lock on the orb. A crimson dry-brush cut crosses the cloak beneath the mask.

| File | Use |
|---|---|
| `phantom-emblem.svg` | Primary emblem on white or canvas. Print, posters, about pages, splash. Vector, 1024 artboard, ~1.8 MB (dense artwork). For screens use the PNGs in **Artwork**. |
| `phantom-emblem-inverse.svg` | The same on matte black, with the silhouette carried by rim light. Boot screens, dark heroes. |
| `phantom-monogram.svg` | Head-and-shoulders crop with enlarged eyes for 16–128px: favicons, tabs, the rail, docs. |
| `phantom-app-icon.svg` | The monogram on black for app, launcher and drive icons. |
| `phantom-wordmark.svg` / `-inverse.svg` | PHANTOM in ink, PORTALS in crimson, a dry-brush underline, a graduated rule and mono sublines. Text is outlined Space Grotesk / JetBrains Mono, so no fonts are needed. |
| `phantom-lockup.svg` | Monogram + wordmark, horizontal. Headers, documents, installer banners. Minimum height 40px. |

Inks: `#151519` ink, `#A0112B` crimson, `#B8143E` hero crimson, `#EE5367` electric (eyes, laser line, lock), `#F6F5F2` canvas for light and rim light.

Rules: one Phantom per surface; clear space is a quarter of the emblem's width; never recolour the figure, add a second character, stretch it, or place the emblem over busy art.
