# Prompt library

Reusable prompts for everything Polka Portals makes with AI: images (hero art, backgrounds, textures, HUD overlays, thumbnails, album art), UI builds by coding agents, design audits, and the shared negative lists they all append.

Every prompt is a Markdown file with front matter that follows [`_schema/prompt.schema.json`](_schema/prompt.schema.json). The catalog [`INDEX.json`](INDEX.json) is generated by `python3 80_TOOLS/index-prompts.py`, which also validates every prompt and checks that its `canon_refs` and `negative_refs` exist.

## How to use a prompt
1. Open the prompt, read **Use** and check its status is CURRENT.
2. Copy the **Prompt** block; fill the `{{VARIABLES}}` (defaults are in the table).
3. Append the negative lists named in `negative_refs` (image tools with a negative field: paste them there; others: add "Avoid: …").
4. Apply the **Tool notes** for your tool. The prose stays the same across tools.
5. Review the result with [PP-AUD-IMAGE-001](design-audit/PP-AUD-IMAGE-001-generated-image-review.md) (images) or [PP-AUD-CANON-001](design-audit/PP-AUD-CANON-001-canon-compliance.md) (UI).
6. Keep a result? Save it into `30_ASSETS/…` with a sidecar whose `source.prompt_id` is the prompt id. It starts as DRAFT.

## Writing a new prompt
Copy [`_schema/prompt.template.md`](_schema/prompt.template.md), take the next free id in its series, set `status: DRAFT`, run `python3 80_TOOLS/index-prompts.py`, and promote it to CURRENT once a result has passed review. Bump `version` (semver) when the wording changes; never reuse an id.

## House rules for image prompts
- Describe the style in words — never name living artists or ask to imitate a specific tattoo artist, studio or stock image ([ADR-0007](../00_START_HERE/decisions/ADR-0007-third-party-references.md)).
- Three inks only: ink black `#151519`, warm paper `#F6F5F2`, blood crimson `#A0112B` / `#B8143E`; electric `#EE5367` only as a tiny point of light.
- One Phantom, matching [the anatomy](../10_DESIGN_SYSTEM/visual-language/the-phantom.md), or none.
- No text in generated images unless the prompt says so; add typography in layout, with the real fonts.
- Generated images never go straight into the product: they pass review, get a sidecar, and start as DRAFT.
